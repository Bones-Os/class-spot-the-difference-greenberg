# class-spot-the-difference-greenberg
Title: Proj1
Project goal: The goal of this project is to practice basic OOP in C++ while using 2-D arrays
Important files: proj1.cpp, at least one of the picX.txt files (where "X" is replaced with "1", "2" or "3")


A spot the difference game in C++ which uses three different ASCII art text files. All UI is text.

Note that this was an academic assignment. That means that the function headers as well as what program should do were given by the professor. The art (pic1.txt thru pic3.txt) was also supplied.
